# Incandescent Lamp

The **Incandescent Lamp** is a light source that emits light when powered.
Besides being decorative and providing illumination, it is also used to speed-up the growth of crops when used in conjunction with the <McItem slug="techreborn:greenhouse_controller" inline={true}/>.
