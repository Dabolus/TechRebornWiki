# HV Cable

**HV (High Voltage) Cable** transfers energy through it. For more details and how to use, read [general information about Cables](/docs/blocks/cables).

| Tier    | I/O Rate   | Buffer   |
|---------|------------|----------|
| Extreme | 2,048 E/t  | 8,182 E  |
